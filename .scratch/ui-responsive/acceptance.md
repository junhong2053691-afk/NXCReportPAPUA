# 上线验收清单 · 手机适配（`7f6d448` → `8a8d07e`）

**怎么验：** 至少一台真手机（iPhone 和 Android 各一台最好）+ 一台电脑。
手机用 **operator 账号**、电脑用 **admin 账号**。打开前先清缓存或用无痕窗口。
⚠️ = 会写数据，用一笔可以撤回的单子，或在测试公司上做。

## A. 员工每天在手机上做的事（最优先）

| # | 功能 | 怎么验证 | 通过标准 |
|---|---|---|---|
| A1 | 底部标签栏 | 手机打开当日流水页，再点「渠道」进支付渠道页，各看一眼屏幕底部 | 从左到右是「菜单 / 流水 / 待处理 / 调钱 / 渠道」五个按钮，待处理带红色数字；**operator 也能看到「菜单」**；当日流水页「流水」是蓝色，支付渠道页「渠道」是蓝色 |
| A2 | 待处理卡片 | 点「待处理」 | 每笔是一张卡片，姓名完整不截断，MODE / BANK / REMARK 竖排，底部有大的「审批 / 跳过」，**不用左右滑** |
| A3 ⚠️ | 审批一笔 | 选 MODE、BANK，点「审批」 | 卡片消失，角标减一，流水里多一条，渠道余额变化正确 |
| A4 ⚠️ | 拆分调钱 | 找一笔 WITHDRAW，MODE 选「拆分调钱」，加两个协助方 | 面板完整展开，金额不对时「审批」是灰的，对上后能审批 |
| A5 ⚠️ | 跳过与恢复 | 跳过一笔（填原因）→「已跳过」页签里点 Restore | 原因弹窗全屏，按钮贴底；恢复后回到平台订单 |
| A6 | 流水压缩卡片 | 点「流水」 | 跳到流水表，标题没被筛选条挡住；每张卡片只有两行（时间·金额 / 状态·姓名） |
| A7 | 展开卡片 | 点一张卡片空白处，等 10 秒 | 展开后出现 BANK、单号、备注和 历史 / 编辑 / 删除；**10 秒后仍是展开状态** |
| A8 ⚠️ | 编辑流水 | 展开 → 编辑 → 改 REMARK → ✓ | 卡片变成竖排表单；点 STATUS / BANK ACC 弹出的选择列表实底、不透字，**手机键盘弹起后列表仍贴着输入框**；保存后余额正确 |
| A9 ⚠️ | 删除与恢复流水 | 删除一条（填原因）→ 筛选条「⋯」→ 最近删除 → 恢复 | 「最近删除」每条是卡片，「恢复」是底部大按钮；恢复后余额回到原值 |
| A10 ⚠️ | 调钱 | 点「调钱」，填金额、STATUS、BANK，保存 | 表单全屏，「取消 / 保存」钉在底部，键盘弹起时按钮不被挡住 |
| A11 | 筛选条 | 往下滚流水 | 日期 / 状态 / 搜索钉在顶部；改日期、搜名字都能正常过滤 |
| A12 | 回到顶部 | 滚过约两屏 | 右下角出现「↑」，在标签栏上方；点一下回到顶部；**不挡住卡片上的按钮** |
| A13 | 渠道 | 点「渠道」 | 跳到支付渠道页（独立一页，不再是弹窗）；「+ 新渠道」独占一行；展开一个渠道能看到最近 10 笔 IN / OUT |
| A14 ⚠️ | 渠道操作 | 编辑一个渠道（不改内容直接保存）；勾 / 取消「使用中」 | 编辑表单全屏可滚，保存成功；勾选框能点中（**已知只有 16px，偏小**） |
| A15 | 渠道列表 | 支付渠道页往下滚 | 每个渠道一张两列卡片，不用左右滑；运营中 / 封禁中 / 已归档页签能切 |
| A16 | 未对平提醒 | 有 C STATUS 未对平时看提醒 | 每条是整行小卡片（不是大白椭圆），「查看流水」能点 |
| A17 ⚠️ | 实时收款 | 点「待处理」，看浮层头部；点「实时收款 N」，勾掉一户再勾回来 | 头部只有一个「实时收款 N」按钮（没选时是橙色「未设置实时收款银行」），**不会折成好几行**；弹层每行够大、勾得中，N 跟着变；充值单 BANK 下拉只列勾选的户，末尾「其他渠道…」能展开完整列表 |
| A18 | 跨公司来单（operator，授权 ≥2 家） | 停在 A 公司，让 B 公司进一两笔待审批 | 底栏上方只出现**一条**「别家待审批 N / B 公司 N」，不会叠好几条、不压顶部筛选条；打开接单浮层时它贴屏幕最底，浮层右上角 × 没被挡，最后一张卡的「审批」能点到；点它切到 B 公司并打开接单区，点 × 收起 |
