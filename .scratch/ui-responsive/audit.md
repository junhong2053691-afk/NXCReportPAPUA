# UI 巡检清单（2026-11-05）

真实服务 + 真实库，内置浏览器逐页测量。17 个导航页 × 375 手机 / 768 平板 / 1366 笔记本，
外加银行页三个弹窗（待处理、渠道管理 + 明细）。

测量口径（脚本在每页跑一遍）：

- **被裁**：`overflow:hidden/clip` 且内容大于盒子（排除 `.sr-only`）
- **越界**：元素右边超出视口、且没有任何可滚动祖先兜住
- **横滚**：`overflow:auto/scroll` 容器里内容比容器宽（数字 = 容器宽 / 内容宽）
- **截断**：`text-overflow:ellipsis` 实际生效的格子数

## 结论先说

1. **整页层面没有真正的裁剪**：17 页在三个宽度下都没有越界、没有整页横滚，
   `overflow:hidden` 也没吃掉内容（1366 下侧栏收成图标栏，标签隐藏是设计如此）。
2. **「看不全」全部来自三张宽表 + 一列截断**，集中在银行页：

| # | 位置 | 375 手机 | 768 平板 | 1366 笔记本 | 说明 |
|---|---|---|---|---|---|
| A | 银行页流水表 `.sheet-table-wrap`（14 列） | 346 / 1334 | 729 / 1334 | **1223 / 1334** | 笔记本上也差 111px；手机上是 4 屏宽 |
| B | 待处理弹窗 `#pending-modal .table-wrap` | **310 / 1222** | 692 / 1222 | 不横滚 | 手机上「审批」按钮在最右，要横拖约 3 屏才点得到 |
| C | 待处理弹窗 USER 列 | 69 格截断 | — | **68 格截断**（172px 宽） | `A5A160690 / Harmanjot Singh Jhamant` 只剩前半；审批时看不全客户名 |
| D | 银行页流水在页面里的位置 | 表格顶在 y≈3046（页高 3202） | y≈3037 | 首屏下方 | 手机上要先滚过约 3.7 屏 KPI/卡片才到流水 |
| E | 渠道卡片 `.bk-channel-list` | 横滚 | 729 / 795 | 不横滚 | 平板上差 66px |
| ✅ | 渠道明细「最近 10 笔」`.bkd-tx-col` | 282 / 640（兜底横滚） | 675 / 675 | 1019 / 1019 | **本轮已修**（IN/OUT 上下堆叠，`style.css` `.bkd-tx-wrap`） |

3. **其他页面的表格**（交易、客户、日报、榜单、月报、往来账、TOP REFERRAL、审计、账号、设置）：
   1366 下全部一屏装下；375 下都是 `.table-wrap` 横滚——能用，但手机上读表格基本靠横拖。
4. **首页手机版**：没被裁，但充值/提现/总客户各占一整行卡片，首屏只看得到净输赢 + 充值。
