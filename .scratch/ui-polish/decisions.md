## 约束（来自 CLAUDE.md，实施时逐条遵守）

- 改了 `style.css` / `public/js/*.js` 就换 `server/index.js` 里对应的 `?v=`。
- CSP `script-src 'self'`：不加内联脚本、`on*`、CDN。
- 页名、说明文字改动要同步 `i18n.js` 字典（中英切换从中文原文翻译）；`I18N_ATTRS` 不加 `value`。
- 租户数据保持 `translate="no"`。
- 手机宽表的 `data-m` 不动（`mobile-table-drawer.test.js` 数着张数）。
- 跨公司来单汇总条、底部标签栏、接单浮层这些上一轮定下的手机交互不动。
- 银行两页先在**最新代码**的实例上复核，再改（巡检实例的页面骨架是旧版）。

## 交付顺序

每组单独提交，用户看过再做下一组。

1. **标尺进 CSS**：`:root` 的字号 token 收成 8 档、加控件高度 token（`--control-h` 36 / `--control-h-sm` 32 / 手机 44）；只加和改值，不删旧变量名的引用。
2. **页面骨架**：取消顶栏 → 标题行（含银行两页）、页名统一、去英文眉题、删说明文字、首页去「洞察工作区」（Q3 / Q6–Q11）。
3. **字号**（`/impeccable typeset`）：全站字号收进 8 档，表格 12px，8–9px 标签抬上来，F1。
4. **控件高度**（Q1）：按钮 / 输入框 / 下拉 / 页签 / 勾选框统一，修 D1–D6。
5. **布局**（`/impeccable layout`）：表单页限宽 960、KPI 网格每行最多 4 张、首页近 7 天整宽、F2。
6. **逐页收尾**（`/impeccable polish`）：当日流水 / 支付渠道 → 总览报表 → 设置类，1366 / 1920 / 360 × 亮 / 暗截图验收。

impeccable 检测脚本报的 side-tab 左边框（状态提醒）、弹性缓动、侧栏宽度过渡都是精修前就有的写法，不在本轮「只理尺寸」范围内，未动。间距（padding 127 种）、圆角、断点（17 种）也留给下一轮。
